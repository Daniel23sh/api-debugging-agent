# APILens V1 baseline — 2026-10-18

This is one approved live run of all 18 fixed V1 cases, followed by the unchanged six evaluator families. No completed paid case was repeated. An application return is distinct from a successful investigation.

## Observed results

- All 18 executions returned diagnoses and all 18 evaluation bundles completed; no execution exception, missing snapshot, missing evaluator unit or evaluator error occurred.
- Expected final status: **14/18 matches**, **4/18 mismatches**, zero missing. Actual statuses: 13 RESOLVED, 5 INCONCLUSIVE.
- Strict success: **13/18** — expected final status, CORRECT root cause where applicable, and GROUNDED evidence. This includes 12 bug cases and the intentionally inconclusive case.
- Five investigations are ineligible for convergence: four status mismatches and one UNGROUNDED diagnosis despite a matching RESOLVED status. Neither response clarity nor a matching status compensates for those failures.
- Structured agent errors: ENDPOINT_NOT_ALLOWED=3; MODEL_OUTPUT_VALIDATION_ERROR=2. These are agent investigation/output failures, not judge or baseline infrastructure failures.

## Limitations

- Label distributions use scored units; states and missing units are reported separately.
- Observed sums/means are partial when missing_cases is nonzero; total_all_cases is then null.
- Convergence uses only successful comparable observed paths and does not prove optimality.
- Judges are qualitative measurements, not ground truth; no aggregate quality score is computed.
- One observed run per case; results are not a statistical reliability estimate.
- 13 successful runs includes the expected inconclusive case; convergence is available only for 12 successful bug cases with paraphrase groups.
- All agent token counts were observed; judge tokens and latency are excluded from agent metrics. No billing-cost total is claimed.
- Phoenix links reference the retained local server/project and require that private storage to remain available.
- Raw snapshots and judge explanations are retained only in ignored local artifacts; this report contains aggregate counts, controlled labels and identifiers.
- V1 agent, dataset and evaluator semantics were frozen. No Phase 9 error attribution, V2 optimization or additional paid rerun was performed.
