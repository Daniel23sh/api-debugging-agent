## Why this experiment

APILens is a small Backend / Applied AI case study. Its core already
includes a controlled V1→V2 experiment demonstrating evaluation-driven iteration.
The latest milestone adds an evidence-backed fix for a current output-acceptance
failure: the model's JSON Schema now describes existing diagnosis status semantics.
This verification tested whether the current system handles the full frozen
dataset, including no-bug controls, without regressions elsewhere.

The approved approach was **one new 18-case verification**, not two fresh 18-case arms. A contemporaneous
with/without-schema-description comparison would isolate that change more cleanly,
but doubles collection and judging and still has only one sample per case/arm.
The current defect also has deterministic semantic-validation regression tests and
separately recorded live before/after observations. A new controlled causal claim
is not needed to establish presentation readiness.

V3 measures the present system. Any V2→V3 comparison is **historical/descriptive**:
there are other source changes since V2, time/model drift and sampling/judge noise.
Do not claim any score difference was caused solely by schema guidance.

## Existing runner, explicit V3 identity

V3 reuses collection, evaluators, storage, metrics, report rendering and trace
verification. The only runner extension is a third explicit experiment identity:
`apilens-v3-verification` with project `apilens-v3-<experiment-id>`. The historical
V1/V2 controlled comparator intentionally rejects V3; its single-instruction-change
assumptions do not describe current-source verification. Its exact historical

First run deterministic checks with no credentials:

```bash

PYTHON_DOTENV_DISABLED=1 python -m evaluation.baseline smoke \
  evaluation/artifacts/baseline/v3-offline-UNIQUE --variant v3
```

Use a fresh path each time. Smoke uses mocked decisions/judgments with real Sandbox
operations. It does not measure live quality or initialize a paid experiment.

backend credentials configured privately. It records the original procedure;
do not rerun it into this existing experiment directory:

```bash

python -m evaluation.baseline_live preflight \
  evaluation/artifacts/baseline/v3-2026-10-25-01 --variant v3 \
```
